## What you get on StartOS

The Web Interface contains a searchable seven-game launcher, game controls, touch-capability badges, fullscreen actions, and an offline Open Source Licenses page. Games load from your StartOS server and do not need external websites, ads, accounts, or trackers.

## Getting set up

1. Open the **Web Interface** after Browser Arcade reports healthy.
2. Search by title or choose a genre if you want to narrow the catalog.
3. Select **Play** on any card. Use your browser's Back action to return to the launcher.
4. Select **Play fullscreen** when it is available. Press Escape to leave fullscreen.

## Controls

- **2048:** Arrow keys or WASD. Swipe on a touch screen.
- **Radius Raid:** WASD or arrow keys to move, mouse to aim and fire, F for autofire, P to pause, and M to mute.
- **BrickIt:** Arrow keys or the on-screen touch controls.
- **BounceIt:** Arrow keys to move, Space for boost, or on-screen touch controls.
- **FloodIt:** Select colors with the mouse or touch.
- **SweepIt:** Use mouse buttons or the on-screen dig and flag modes.
- **SnakeIt:** Arrow keys or swipe controls.

Audio can require a click or key press before the browser allows playback. If keyboard controls do not respond, click the game once to give it focus.

## Licenses and offline use

Open **Open Source Licenses** from the launcher to read source credits, pinned revisions, attribution, and full local license texts. The page and all games remain usable without Internet access.

## Limitations

Scores and saves are stored by your browser, not on the StartOS server. They are not included in StartOS backups, do not synchronize between devices, and can reset when you clear browser storage. Using another Browser Arcade hostname or browser profile can create a separate save state.

Gamepad support is not guaranteed. Radius Raid and other older HTML5 games can vary across browsers. There are no accounts, multiplayer, server-side saves, custom game uploads, or ROM support.

If a game appears stuck, reload the page, confirm the game has keyboard focus, and try a current browser. Fullscreen support varies by browser and mobile platform.
